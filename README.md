# Horizon builds

Finished, ready-to-play builds of Horizon (Minecraft: Java Edition rewritten in Rust) for the Quicks launcher.

Each release here holds the game builds and their SHA-256 checksums, nothing else: no source code and no keys live in this repo. The source stays in a private repo.

Horizon needs your own legal copy of Minecraft: Java Edition and your Microsoft account sign-in, same as the official launcher. It ships no Minecraft code or assets.

Made by Quickdeveloper.
